# Abbey Road

面向大学生的课表与日程管理工具。Android 与 Windows 两端，功能与界面一致，数据只保存在本机。

## 今日

- 三栏布局：本周概览、今日日程、最近的课。每一栏都可以点开放大，放大后看详细信息，其它栏相应收窄。
- 最近的课：显示时间、地点、老师、节次、周次、备注，逐项点开即可修改；卡片会按离上课的远近变色（阈值和颜色可调）。
- 今日日程：每节课一条，含时间、课程名、地点、老师、节次与周次，点开查看详情。
- 本周概览：周视图与月视图，可切换周次与日期；放大后可以左右滑动查看一周中更多的日期。考试、讲座等活动以专属颜色标出。
- 顶栏显示当前时间，并提供前一天 / 今天 / 后一天快捷切换。

## 课表

- 周表：一周七天日期在上，左侧是节次与起止时间，一屏看完本周课程。
- 编辑课程：点任意课程块即可修改课程名、老师、地点、星期、节次、上课时间、周次与单双周、本次备注与本课备注、颜色和课程类型；作用域可选「仅这次」或「所有时段」。
- 排课规则：单双周、周次范围、停课、补课、调课、换教室，冲突会提前提示。
- 调休与借课：把某一天的课整体搬到或复制到另一天，执行前先给出预览。
- 长按周表空白处可快速新增课程或考试、讲座、活动。
- 支持多学期，可在周表页切换学期。

## 作业与长期任务

- 作业从课程备注中自动识别，识别方式可选「一行算一条」或「智能识别」。
- 今日日程底部汇总当天的作业，可展开查看；左右滑动即可划掉，划掉的进入「已完成」区，保留当天，之后折进「更早的已完成」，超过一周自动隐藏但仍可找回。
- 未完成的作业可以按课程分组显示，分组开关放在设置里。
- 作业记录页提供未完成、已完成、完成率统计，也能找回被隐藏的条目。
- 长期任务：志愿时长、阅读量这类需要累计的目标，各自统计今日、近七天与累计进度和完成率，每一笔都可以单独撤销；每条单独决定是否显示在今日页。

## 导入与同步

- 提示词导入：复制应用内提供的固定提示词交给 DeepSeek、豆包等大模型，把课表图片整理成文本后粘贴回来，解析、预览、逐条修正，再应用到课表。
- 文本格式使用自定义分隔符，并支持颜色字段，复制粘贴过程不易错乱；课表排到默认节次表之外时会自动补齐节次。
- 也可以手动逐条添加课程，或添加考试、讲座、活动。
- 配置文件：导出为 JSON 文件（另存为、导出到微信、复制文本均可），在另一台设备导入；支持从文件、粘贴文本，或直接从导出目录里挑选。
- 合并前会先预览新增项与冲突项，按内容比对，不会把同一门课导入成两份。

## 系统集成

- 地点：自动去掉教室号这类细节，缺少大学名或城市时自动补全，然后打开高德、百度或系统地图；最终查询词可以手动修改。
- 日历与闹钟：把课程写进系统日历或设置闹钟，桌面端降级为系统日历与通知。
- 桌面卡片：Android 端提供五种小组件，分别是今日头、下一节课、今日课程清单、本周迷你课表与快捷入口。
- 可以复制课程信息，方便转发。

## 外观与设置

- 主题跟随系统，也可以固定浅色或深色；主题色、毛玻璃强度、动画速度、震动反馈均可调整。
- 布局与尺寸：左右与上中下两种版式，另有左手模式、今日日程紧凑卡片，栏宽与栏高用滑块调整并实时预览。
- 课程配色：多套配色方案，按课程类型自动分色，也可以逐门指定颜色或用色盘自定义。
- 节次时间：默认十二节，可逐节修改；学期开始日期、周数范围也在这里设置。
- 过渡动画样式可以在开发者模式里更换，入口是长按设置中的「外观」，平时不需要用到。

## 安装

- **Android**：从 [Releases](https://github.com/EtoileZzz/AbbeyRoad----ScheduleApp/releases) 下载 APK 安装，需要 Android 12 及以上。
- **Windows**：从同一页面下载安装程序，支持 Windows 10 和 11。

## 数据

数据保存在本机。应用不发起网络请求，不收集信息，也没有账号。

跨设备同步通过手动导入导出配置文件完成，文件由使用者自己保管。导入前会先预览新增项与冲突项，确认后才合并。设置里可以导出备份，也可以清空全部数据。

## 从源码构建

界面代码在 `app/`，Android 与 Windows 外壳分别在 `android/` 和 `windows/`，两个目录下的 `build.ps1` 可以产出 APK 与安装程序。构建分别需要 JDK 17 与 Android SDK，以及 .NET Framework 与 WebView2 SDK。
